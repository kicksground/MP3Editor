# 🎵 MP3 편집기

맥북에서 **아무것도 설치하지 않고** 바로 사용할 수 있는 오디오 편집기입니다.

## 🌐 바로 사용하기 (추천)

**👉 https://kicksground.github.io/MP3Editor/**

위 주소를 북마크해 두면 다운로드 없이 언제나 최신 버전을 쓸 수 있습니다.
주소만 웹일 뿐, 오디오 파일 처리는 100% 내 컴퓨터 안에서만 이루어집니다 — 파일이 인터넷으로 전송되지 않아요.

인터넷 없이 쓰고 싶다면 아래처럼 ZIP으로 내려받아 `index.html`을 더블클릭해도 똑같이 작동합니다.

모든 작업은 내 컴퓨터 안에서만 이루어집니다. 오디오 파일이 인터넷으로 전송되지 않으니 안심하고 사용하세요.

---

## 📥 내려받아서 사용하는 방법 (선택)

1. 이 GitHub 페이지에서 초록색 **`< > Code`** 버튼을 클릭합니다.
2. **`Download ZIP`** 을 클릭해서 다운로드합니다.
3. 다운로드된 ZIP 파일을 더블클릭하면 압축이 풀리면서 폴더가 생깁니다.
4. 폴더 안의 **`index.html`** 파일을 더블클릭합니다.
5. 브라우저가 열리면서 편집기가 실행됩니다. 끝!

> 💡 폴더 안의 `lame.min.js` 파일은 MP3 저장에 필요한 부품입니다. `index.html`과 같은 폴더에 함께 있어야 하니 삭제하거나 이동하지 마세요.

## 🎧 사용 방법

| 하고 싶은 일 | 방법 |
|---|---|
| 파일 열기 | 화면에 오디오 파일을 드래그하거나, 클릭해서 선택 (MP3·WAV·M4A·AAC·OGG, 동영상 MP4의 소리도 가능) |
| 구간 선택 | 파형(물결 그림)을 마우스로 드래그 |
| 파형 확대/축소 | 파형 위에서 마우스 휠 또는 트랙패드 스크롤 (`전체 보기` 버튼으로 복귀) |
| 확대 상태에서 좌우 이동 | `Shift+휠`, 트랙패드 좌우 스크롤, 또는 파형 아래 **미니맵(작은 전체 파형)을 드래그** |
| 재생 위치 이동 | 파형을 클릭 |
| 재생 / 일시정지 | `▶ 재생` 버튼 또는 `스페이스` 키 |
| 원하는 부분만 남기기 | 구간 선택 → `📌 선택 구간만 남기기` |
| 필요 없는 부분 삭제 | 구간 선택 → `✂️ 선택 구간 삭제` 또는 `삭제(⌫)` 키 |
| 소리 점점 커지게/작아지게 | 구간 선택 → `📈 페이드 인` / `📉 페이드 아웃` |
| 볼륨 조절 | 슬라이더를 움직이면 재생 중인 소리에 바로 반영(미리듣기). `파일에 적용`을 눌러야 저장에 반영 |
| 소리가 작을 때 | `🎚 음량 최적화` (소리가 잘리지 않는 한도까지 자동으로 키워줍니다) |
| 목소리 강조 | `🎤 목소리 강조 (베타)` — 사람 목소리 대역만 남겨 배경음을 줄입니다 |
| 되돌리기 | `↩️ 실행 취소` 버튼 또는 `⌘Z` |
| 저장하기 | 저장 범위(전체/선택 구간만)와 음질 선택 → `⬇ MP3로 저장` (또는 `⬇ WAV로 저장`) |
| 저장 위치 지정 | Chrome에서는 저장 시 폴더와 파일 이름을 고르는 창이 뜹니다. Safari 등 미지원 브라우저는 다운로드 폴더에 저장돼요 |
| 선택 부분을 따로 편집 | 구간 선택 → `⬇️ 선택 구간을 새 클립으로 추가` — 화면 아래에 클립 파형이 나타나고, 원본은 그대로 둔 채 클립만 자르고 페이드를 넣어 별도 파일로 저장할 수 있어요 |
| 클립 여러 개 만들기 | 버튼을 누를 때마다 클립이 아래로 계속 추가됩니다 (클립1, 클립2, …). 클립 안의 선택으로 또 새 클립을 만들 수도 있고, 각 클립은 `✕ 클립 닫기`로 정리합니다 |
| 클립 순서 바꾸기 | 클립 왼쪽 위 `⠿` 손잡이를 드래그해서 위아래로 이동 (화면 가장자리에 닿으면 자동 스크롤) |
| 클립 이어 붙이기 | `🔗 이어 붙이기` — `이어 붙이기 포함`에 체크된 클립들만 화면 순서대로 연결한 새 클립(합본)을 만듭니다. 옆의 `무음` 선택으로 클립 사이마다 0.5~3초의 조용한 간격을 넣을 수 있어요 |
| 클립 구분하기 | 클립마다 색이 다르게 표시되고(제목·파형·왼쪽 띠), `✏️`로 이름을 바꿀 수 있으며(저장 파일명에도 사용), 제목 옆에 원본의 어느 구간에서 왔는지 표시됩니다 |
| 다시 실행 | `↪️ 다시 실행` 버튼 또는 `⌘⇧Z` — 실행 취소를 되돌립니다 |

> 🔴 파형에 **빨간색**으로 표시되는 부분은 소리가 최대 한계에 닿아 잘린(클리핑) 곳입니다.
> 볼륨을 100% 이상으로 키우면 클리핑이 생길 수 있으며, 적용 후 경고 메시지로 알려드립니다.
> 안전하게 키우려면 `🎚 음량 최적화`를 사용하세요.

저장 버튼을 누르면 편집된 파일이 맥북의 **다운로드 폴더**에 저장됩니다.

> ⚠️ 구간을 선택하지 않은 상태에서 볼륨·페이드·무음·음량 최적화를 누르면 **전체 오디오**에 적용됩니다.

## 🛠 기술 정보 (궁금한 분만)

- 순수 HTML + JavaScript로 만들어져 서버나 설치 과정이 필요 없습니다.
- 오디오 해석/재생: 브라우저 내장 **Web Audio API**
- MP3 인코딩: [lamejs](https://github.com/zhuker/lamejs) (LGPL 라이선스)
