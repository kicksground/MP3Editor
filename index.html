💡 사용 팁  ·  파형을 클릭=재생 위치 이동, 드래그=구간 선택.  ·  마우스 휠 확대/축소, Shift+휠 좌우 이동, 파형 아래 미니맵을 드래그해도 이동합니다.  ·  스페이스 재생/정지  ·  ⌫ 선택 삭제  ·  ⌘Z 실행 취소, ⌘⇧Z 다시 실행 (마지막에 클릭한 파형에 적용)  ·  구간을 선택하지 않으면 볼륨·페이드·무음은 전체에 적용됩니다.  ·  볼륨 슬라이더는 재생 소리에 바로 반영되고, ‘파일에 적용’을 눌러야 저장에도 반영됩니다.  ·  ⬇️ 선택을 새 클립으로: 원본은 그대로 두고 선택 부분을 아래 클립으로 복사해 따로 편집·저장합니다. 여러 번 눌러 계속 추가할 수 있어요.  ·  🔗 이어 붙이기: ‘이어 붙이기 포함’에 체크된 클립들을 화면 위에서부터 순서대로 연결한 새 클립을 만듭니다. 옆의 사이 무음을 고르면 클립 사이마다 그만큼의 조용한 간격이 들어가요.  ·  클립 왼쪽 위의 ⠿ 손잡이를 드래그하면 클립 순서를 바꿀 수 있고, ✏️로 클립 이름을 바꿀 수 있습니다. 클립마다 색이 달라 구분하기 쉬워요.  ·  🎙️ 녹음: 파일 없이 시작하면 녹음이 원본으로 열리고, 편집 중이면 새 클립으로 추가됩니다. 처음 사용할 때 브라우저의 마이크 권한 요청을 ‘허용’해 주세요.  ·  파형의 빨간 부분은 소리가 최대 한계에 닿아 잘린(클리핑) 곳입니다.  ·  저장 시 Chrome에서는 폴더를 직접 고를 수 있고, 위치 선택을 지원하지 않는 브라우저(Safari 등)는 다운로드 폴더에 저장됩니다.
